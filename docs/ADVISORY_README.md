# 자문자 안내 — 경기도 후보 공간 자문용 검토 화면

**이 화면은 연구 결과를 최종 확정하기 위한 화면이 아니라, 현재 데이터와 방법론을 검토받기 위한 자문용 화면입니다.** 로그인·설치가 필요 없고, 일반 브라우저로 링크를 열면 됩니다.

1. **목적** — 경기도의 현재 데이터·방법론·한계를 그대로 보여 드리고, 무엇이 실제와 다른지, 무엇이 더 필요한지, 어떤 방법이 타당한지 의견을 받습니다.
2. **보는 방법** — ① 탭에서 잘 아시는 시군 → 읍면동 → 후보 하나를 고르고, 근거 레이어(필지·읍면동·산업단지·계통·기존 시설)를 켜서 실제 공간과 비교해 주세요. 후보 상세의 "데이터 출처 보기"에서 자료 기준 시점을 볼 수 있습니다. ② 탭에서 A(공간 규모)·B(계통 참고값)·C(산업단지 거리)와 여러 조합을 비교하고, ③ 탭에서 지자체 사용 과제를 해 보세요.
3. **후보 공간** — 이 분석의 판정 조건을 통과한 농지 필지를 21m 이내로 이어 묶은 공간입니다. 빠진 공간이나 반대로 포함된 공간이 있는지 봐 주세요.
4. **10/20/50MW** — 면적 × 0.045 kW/㎡ 로 환산한 참고 규모입니다. 실제 설치 가능 용량이나 계통 접속 가능 용량이 아닙니다.
5. **계통 참고값** — 후보가 있는 읍면동 단위의 참고값(한전 공표 자료, 조회 2026-08-19)입니다. 개별 사업의 실제 접속 가능성을 뜻하지 않습니다.
6. **기존 시설 자료** — 확보한 공개 자료 중 위치가 확인된 시설만 보여 줍니다. 전수조사가 아니므로 0곳이 시설이 없다는 뜻은 아닙니다.
7. **21m** — 가장 작은 공간 분석 단위입니다. 실제 사업 단위(클러스터)를 어떻게 묶을지는 정해지지 않았습니다.
8. **가중합** — ② 탭의 가중합은 방법론 자문용 실험입니다. 처음 값 33/33/34는 단순한 시작값이며 권장 가중치가 아닙니다.
9. **이 화면에서 확인할 수 없는 것** — 용도지역·주요 제외조건(규제) 레이어는 이번 화면에 공개하지 않았습니다. 경기도 밖 자료와 원천(raw) 자료도 없습니다. 경사 조건의 단위(15° / 15%)와 일부 원천의 수집일은 기록이 없어 확인 중입니다.
10. **의견 남기기** — 각 과제 칸에 판단(완료·헷갈림·못 찾음)과 메모를 남겨 주세요. 메모 앞에 [사실 확인] · [방법 의견] · [사용성] 중 하나를 붙이고, 해당 후보 공간 번호나 필지 번호를 함께 적어 주시면 좋습니다. **의견은 서버로 자동 전송되지 않고 지금 쓰시는 브라우저에만 저장됩니다.** 마지막에 "의견 내보내기" 탭에서 JSON 또는 CSV 파일로 내려받아, 파일 이름에 성함을 붙여 담당자에게 보내 주세요.
