# 자문자 안내 — 경기도 후보 공간 자문용 검토 화면

**이 화면은 연구 결과를 최종 확정하기 위한 화면이 아니라, 현재 데이터와 방법을 전문가께 검토받기 위한 자문용 화면입니다.** 로그인·설치가 필요 없고, 일반 브라우저로 링크를 열면 됩니다. 정답을 여쭙는 것이 아니므로, 판단하기 어려운 질문은 "판단 어려움"을 고르시거나 비워 두셔도 됩니다.

## 읽기 전에 알아 두실 점

- **후보 공간** — 경기도 법인·국공유 농지 가운데 이 연구의 분석 조건을 통과한 필지를, 21m 이내로 이어진 것끼리 묶은 공간입니다. 가장 작은 공간 분석 단위이며, 실제 사업 단위(클러스터)를 어떻게 묶을지는 정해지지 않았습니다.
- **10 / 20 / 50MW** — 면적에 0.045 kW/㎡를 곱한 참고 규모입니다. 실제 설치 가능 용량이나 계통 접속 가능 용량이 아닙니다.
- **계통 값** — 후보가 있는 읍면동 단위의 참고값(한전 공표 자료, 2026-08-19 조회)입니다. 실제 접속 여부와 용량은 한전 검토로 정해집니다.
- **기존 태양광 시설** — 확보한 공개 자료 중 위치가 확인된 것만 표시합니다. 0곳이라고 해서 시설이 없다는 뜻은 아닙니다.
- **가중합** — ② 탭의 가중합은 방법론 자문을 위한 실험입니다. 처음 값 33/33/34는 단순한 시작값이며 권장 가중치가 아닙니다.
- **이번 화면에 없는 것** — 용도지역·주요 제외조건(규제) 레이어, 경기도 밖 자료, 원천(raw) 자료는 공개하지 않았습니다. 경사 조건의 단위(15° / 15%)와 일부 원천의 수집일은 기록이 없어 확인 중입니다.

## 보는 방법

1. **① 경기도 데이터 검증** 탭 아래 "A. 데이터 확인"의 **검토 사례 3곳**에서 "지도에서 보기"를 누르면 지도가 그 후보로 이동합니다. 전체 후보를 모두 보실 필요는 없습니다.
2. 배경 지도를 "위성"으로 두고, 근거 레이어(필지 점·읍면동 경계·산업단지·계통 참고값·기존 시설)를 켜고 끄며 보세요. 후보 상세의 "데이터 출처 보기"에서 자료 기준 시점을 볼 수 있습니다.
3. **② 방법론** 탭에서 A(면적)·B(계통 참고값)·C(산업단지 거리) 비교와 가중합 실험을 해 보신 뒤, 아래 "B. 방법 검토"에 답해 주세요.

## 드리는 질문

화면의 각 질문 아래에서 선택지를 누르고, 필요하면 메모를 적어 주세요.

**A. 데이터 확인**
- A1. 위성 지도를 켜고 각 사례를 보실 때, 후보 경계 안에 농지가 아닌 것(건물·도로·하천·산림 등)이 섞여 보입니까?
- A2. 후보를 가려낸 조건 가운데, 영농형 태양광 후보를 보기에 빠졌거나 과하다고 생각하시는 조건이 있습니까?
- A3. 자료 기준 시점을 보시고, 입지 검토에 쓰려면 갱신이 가장 시급하다고 보시는 자료를 골라 주십시오.
- A4. 후보를 검토할 때 함께 겹쳐 보고 싶은 공간 자료를 골라 주십시오. (개수 제한 없음)
- A5. (선택) 잘 아시는 지역이 있다면, 실제와 다르게 보이는 곳을 후보 번호와 함께 적어 주십시오.

**B. 방법 검토**
- B1. 면적·계통·산업단지 거리를 하나의 점수로 합치지 않고 따로 비교해 보여 주는 방식이 입지 검토에 도움이 됩니까?
- B2. 영농형 태양광 입지를 검토할 때 중요한 요소에 중요한 순서대로 순위를 골라 주십시오.
- B3. 가중치를 바꿔 보셨을 때 결과가 바뀌는 정도가 납득할 만했습니까? 가중치를 정한다면 누가, 어떤 근거로 정하는 것이 적절합니까?
- B4. 21m 이내로 이어진 필지를 한 후보 공간으로 묶은 것이 실제 사업 단위로 보시기에 어떻습니까? 묶을 때 함께 고려해야 할 것은 무엇입니까?
- B5. 계통 참고값을 화면에 보여 주는 것은 입지 검토에 도움이 됩니까, 오해를 부를 수 있습니까?

**C. 활용 가능성**
- C1. 재생에너지지구 지정을 신청하실 때, 이 화면의 지도·표를 보조자료로 쓰실 수 있을 것 같습니까? 쓰시려면 무엇이 더 필요합니까?
- C2. 내부 검토 자료로 쓰시려면 무엇이 필요합니까? 반대로 외부에 공개되면 지구 지정에 도움이 되지 않을 정보는 무엇입니까?
- C3. 화면 사용해 보기 — 우리 시군 찾기 · 우리 읍면동 찾기 · 눈에 띄는 후보 공간 하나 찾기 · 그 후보가 왜 표시됐는지 이해하기 · 지번으로 필지 찾아보기
- C4. 화면의 50 / 20 / 10MW 표시를 보시고 어떻게 이해하셨습니까?
- C5. 있었으면 하는 기능이나 정보를 적어 주십시오. (개수 제한 없음)
