# 자문자 안내 — 경기도 후보 공간 자문용 검토 화면

**이 화면은 연구 결과를 최종 확정하기 위한 화면이 아니라, 현재 데이터와 방법을 전문가께 검토받기 위한 자문용 화면입니다.** 로그인·설치가 필요 없고, 일반 브라우저로 링크를 열면 됩니다. 정답을 여쭙는 것이 아니므로, 판단하기 어려운 질문은 "판단 어려움"을 고르시거나 비워 두셔도 됩니다.

## 읽기 전에 알아 두실 점

- **후보 공간** — 경기도 법인·국공유 농지 가운데 이 연구의 분석 조건을 통과한 필지를, 21m 이내로 이어진 것끼리 묶은 공간입니다. 가장 작은 공간 분석 단위이며, 실제 사업 단위(클러스터)를 어떻게 묶을지는 정해지지 않았습니다.
- **10 / 20 / 50MW** — 면적에 0.045 kW/㎡를 곱한 참고 규모입니다. 실제 설치 가능 용량이나 계통 접속 가능 용량이 아닙니다.
- **계통 값** — 후보가 있는 읍면동 단위의 참고값(한전 공표 자료, 2026-08-19 조회)입니다. 실제 접속 여부와 용량은 한전 검토로 정해집니다.
- **기존 태양광 시설** — 확보한 공개 자료 중 위치가 확인된 것만 표시합니다. 0곳이라고 해서 시설이 없다는 뜻은 아닙니다.
- **가중합** — ② 탭의 가중합은 방법론 자문을 위한 실험입니다. 처음 값 33/33/34는 단순한 시작값이며 권장 가중치가 아닙니다.
- **이번 화면에 없는 것** — 용도지역·주요 제외조건(규제) 레이어, 경기도 밖 자료, 원천(raw) 자료는 공개하지 않았습니다. 경사 조건의 단위(15° / 15%)와 일부 원천의 수집일은 기록이 없어 확인 중입니다.

## 보는 방법

1. **① 경기도 데이터 검증** 탭 아래 "A. 데이터·후보 결과 검토"의 **검토 사례 3곳**에서 "지도에서 보기"를 누르면 지도가 그 후보로 이동합니다. 전체 후보를 모두 보실 필요는 없습니다.
2. 배경 지도를 "위성"으로 두고, 근거 레이어(필지 점·읍면동 경계·산업단지·계통 참고값·기존 시설)를 켜고 끄며 보세요. 후보 상세의 "데이터 출처 보기"에서 자료 기준 시점을 볼 수 있습니다.
3. **② 방법론** 탭에서 A(면적)·B(계통 참고값)·C(산업단지 거리) 비교와 가중합 실험을 해 보신 뒤, 아래 "B. 방법론 검토"에 답해 주세요.
4. **③ 사용성** 탭에서 지역·지번 검색을 해 보시고, "C1–C3. 화면 사용해 보기"와 "C. 사용성·활용성 검토"에 답해 주세요.

## 드리는 질문

화면의 각 질문 아래에서 선택지를 누르고, 필요하면 메모를 적어 주세요.

**0. 자문자 배경** (① 탭 맨 위)
- 0-1. 주로 경험하신 분야를 골라 주세요. (농업·농지 / 공간정보·GIS / 태양광·재생에너지 / 전력·계통 / 지자체·행정 / 환경·규제 / 기타)
- 0-2. 경기도 농지·입지에 대한 현장 경험은 어느 정도입니까? (많음 / 일부 지역 경험 / 거의 없음 / 판단 어려움)

**A. 데이터·후보 결과 검토** (① 탭)
- A1. 전형 후보 — 이 후보의 위치와 경계를 실제 현황과 비교했을 때, 명백히 맞지 않는 부분이 있습니까?
- A2. 예외 후보 — 도형 면적과 장부 면적이 크게 다른 이 후보를 보셨을 때, 현재 표시 또는 데이터 처리에서 확인이 필요한 부분이 있습니까?
- A3. 제외 사례 — 연구 기준에서는 제외되었지만, 실제 입지 검토에서는 후보로 검토할 필요가 있다고 생각되는 곳이 있습니까?
- A4. 후보가 되면 안 될 것 같은 곳 — 현재 후보 공간 중 실제로는 제외되어야 한다고 생각되는 곳이 있습니까?
- A5. 후보 선정 조건 — 농지 관련 조건, 소유 조건, 농업진흥지역 관련 가정, 경사 조건, 법정 제외조건, 최소면적 조건을 각각 어떻게 보십니까? (적절함 / 너무 엄격함 / 너무 완화됨 / 판단 어려움)
- A6. 빠진 조건 — 현재 후보를 만들 때 빠졌다고 생각하시는 조건이 있습니까?
- A7. 최신성 — 실제 입지 검토에 사용한다고 할 때, 갱신이 특히 필요한 자료는 무엇입니까?
- A8. 추가 자료 — 현재 화면에 없는 자료 중 실제 검토에 꼭 함께 보고 싶은 자료는 무엇입니까?

**B. 방법론 검토** (② 탭)
- B0. 영농형 태양광 입지를 판단할 때 중요하다고 생각하시는 요소를 최대 5개 적어 주십시오.
- B1. 요소의 성격 — 각 요소를 어떤 종류의 정보로 보십니까? (먼저 제외할 조건 / 후보 간 비교 조건 / 최종 사업성 판단 조건 / 참고 정보 / 잘 모르겠음)
- B2. 현재 연구의 세 축 — 후보 공간 규모, 계통 참고값, 산업단지까지의 직선거리를 어떤 방식으로 함께 제시하는 것이 가장 유용합니까?
- B3. 21m 연결 기준 — 21m 이내로 이어진 필지를 하나의 후보 공간으로 묶는 방식이 초기 입지 검토용 분석 단위로 적절합니까?
- B4. 실제 사업 클러스터 — 실제 사업 단위로 묶기 위해 21m 연결 외에 무엇을 추가로 고려해야 합니까?
- B5. 계통 참고값 — 읍면동 단위의 계통 참고값을 후보 화면에 제공하는 것에 대해 어떻게 보십니까?
- B6. 종합점수 — 여러 정보를 하나의 종합점수로 만드는 것이 실제 입지 검토에 필요하다고 보십니까?
- B7. 가중치 결정 — 종합점수를 만든다면 가중치는 어떤 방식으로 정하는 것이 적절합니까?

**C. 사용성·활용성 검토** (③ 탭)
- C1. 지역 검색 — 우리 시군 또는 읍면동을 찾는 것이 쉬웠습니까?
- C2. 후보 이해 — 눈에 띄는 후보 하나를 찾고, 왜 후보로 표시됐는지 이해할 수 있었습니까?
- C3. 지번 검색 — 지번 또는 PNU로 원하는 필지를 찾을 수 있었습니까?
- C4. 50 / 20 / 10MW 표시 — 이 표시는 무엇을 의미한다고 이해하셨습니까?
- C5. 내부 검토에 필요한 정보 — 현재 화면을 내부 검토에 사용하려면 무엇이 추가되어야 합니까?
- C6. 외부 공개 시 주의할 정보 — 오해·민감성 또는 악용 가능성 때문에 제한해야 할 정보가 있다면 무엇입니까?
- C7. 추가 기능 — 실제 업무에 사용한다면 가장 필요할 기능이나 자료는 무엇입니까?

**D. 종합 의견** ("의견 내보내기" 탭) — 현재 후보 공간과 분석 방법을 실제 지자체·전문가의 입지 검토에 활용한다고 가정했을 때, 잘 되어 있는 점 / 반드시 수정할 점 / 추가로 필요한 자료·기능을 자유롭게 적어 주십시오.
